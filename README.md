# Smart ChatBot

A simple rule-based chatbot built using Python.

## Features

- Greets users
- Answers predefined questions
- Shows current date
- Shows current time
- Help menu
- Exit command

## Technologies Used

- Python

## Concepts Used

- Functions
- if-elif statements
- Loops
- Input/Output
- Date & Time Module

## Run

```bash
python main.py
```
